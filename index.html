Instalable y sin conexión

Esta prueba está pensada para teléfonos, tablets, computadoras y trabajo offline.
  • Diseño adaptable para móvil y escritorio.
  • Datos locales con IndexedDB.
  • Instalable como aplicación PWA.
  • Service worker para abrir sin conexión luego de la primera carga.
  • Lista para subir a GitHub Pages.
